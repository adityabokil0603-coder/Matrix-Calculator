# Advanced Matrix Calculator

A menu-driven **Matrix Calculator** developed in **C** as a mini-project to strengthen programming fundamentals, modular programming, matrix mathematics, and software development practices using **Git** and **GitHub**.

The project is being developed incrementally through multiple phases, beginning with basic matrix operations and gradually progressing toward advanced matrix algorithms, statistical analysis, and professional software architecture.
