# Advanced Matrix Calculator

A menu-driven Matrix Calculator developed in **C** as a mini-project to practice programming fundamentals, modular programming, matrix mathematics, and software development using Git and GitHub.

The project is being developed incrementally in multiple phases, starting from basic matrix operations and gradually expanding into a comprehensive linear algebra toolkit with professional software engineering features.
